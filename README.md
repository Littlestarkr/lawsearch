# Happy Oh 법령 길잡이

정확한 법령명을 몰라도 상황을 적으면 관련 법령과 조문을 찾아 주는 검색 페이지입니다.
법제처 국가법령정보 공동활용 Open API를 사용합니다.

- `index.html` : 검색 페이지 (단일 파일)
- `worker.js` : 브라우저에서 법제처 서버를 직접 호출할 수 없을 때 쓰는 Cloudflare Workers 중계 코드 (선택)

### 질문 이해 방식 (2026-11)
- **상황 사전(`TOPICS`)**: 주제마다 상황어(`k`), 연결 법령(`laws`), 조문 핵심어(`t`)에 더해 다음을 둘 수 있다.
  - `all`: 낱말 묶음이 모두 나오면 주제를 잡는다 (예: 직원 + 기술 + 경쟁사 → 영업비밀). 묶음마다 '이 중 하나' 낱말 목록의 배열.
  - `not`: 함께 나오면 이 주제가 아니라는 말 (예: '하자' + '신용장'이면 건설·공사 제외).
  - `arts`: 대표 조문 `[법령명, 제N조, 조문 제목에 들어 있어야 할 말]`. 조문 창 맨 위 '먼저 볼 대표 조문'에 보이며, 번호와 제목이 모두 맞을 때만 쓴다(개정으로 번호가 바뀌면 자동으로 빠진다). 법령명은 같은 주제의 `laws`에 있어야 한다.
  - `ext`: 국내 법령보다 국제 규칙이 기준인 주제의 안내 링크 `{label, url}`.
- **붙여 쓴 낱말**: 띄어쓰기 없는 긴 말은 사전 낱말(`k`·`t`)로 앞에서부터 가장 길게 잘라 읽는다(`segment`, 예: 녹색제품의무구매인증 → 녹색제품/의무구매/인증). 한 낱말짜리 상황어는 잘라 낸 조각과 똑같을 때만 온전히 치고, 더 긴 말의 일부일 뿐이면 약하게 친다(예: '적격심사기준' 안의 '사기'). '인증'·'제품'처럼 두루 쓰는 말(`GENERIC`)은 더 구체적인 사전 낱말이 함께 있으면 약하게 치며, 1위 주제 점수의 40%가 안 되는 주제는 뺀다. 제도명을 추가할 때는 붙여 쓴 형태도 `tests/queries.json`에 넣어 확인한다.
- **조문 순위(조문 창)**: 낱말마다 '질문에 직접 쓴 말(무게 3) / 주제 핵심어(1.5) / 그 밖(1)' × '이 법령 안에서 드문 정도(idf)'로 점수를 매기고, 조문 제목에 나오면 3배로 친다. 질문 낱말이 여럿 함께 나오면 더 올리고, 대표 조문(`arts`)은 점수를 더해 함께 줄 세운다. 1~4위는 '근거'와 함께 바로 보이고 5위부터는 접혀 있으며, 1위 점수의 20%가 안 되는 조문은 뺀다. 질문에 쓴 말이 그 법령에 아예 없으면 안내 문구를 띄운다.
- **법령 약칭(`LAW_ABBR`)**: 질문에 '화관법', '하도급법시행령', '중대재해법상'처럼 약칭이 있거나 정식명을 적으면(띄어쓰기·가운뎃점이 달라도) `expandAbbr`가 정식 법령명으로 풀고, 그 법령 → 시행령 → 시행규칙을 결과 맨 위에 모아 둔다(시행령을 적었으면 시행령부터). 주제 추천·낱말 검색 결과는 그 뒤에 온다. 결과 위에 '약칭 → 정식명'을 보여 준다. 상황 주제와 낱말 검색·조문 순위에는 법령 이름을 뺀 나머지 말만 쓰고(정식명 속 '계약' 때문에 민법이 끼지 않게), 나머지 말이 없으면 그 법령이 들어 있는 주제 하나를 대표 조문용으로 쓴다. 약칭 앞은 낱말 경계여야 하고(‘최근기법’ 속 ‘근기법’은 안 잡음), 뒤에는 다른 말이 붙어도 된다. 관세법처럼 짧은 정식명은 약칭 없이 이름만 둔다. 정식명은 국가법령정보센터 표기 그대로 쓰고 확실한 약칭만 넣는다.
- **부칙 감점**: 조문 순위에서 부칙 조문 점수를 0.2배(`SUPP_FACTOR`)로 낮춰 본칙이 먼저 나오게 하고 근거에 '부칙이라 낮춤'을 붙인다. '부칙' 머리 줄 뒤, 또는 본칙이 제2조 이상까지 간 뒤 제1조로 번호가 다시 시작하면 부칙으로 본다(`markSupp`). 행정규칙은 본문 끝에 붙은 '부칙 <…>'을 떼어 따로 나눈다. 부칙 조문은 대표 조문으로 잡지 않고, 본칙 조문 링크도 걸지 않는다.
- **시험**: 사전을 고친 뒤 `node tests/check-topics.js`를 실행한다. `tests/queries.json`의 질문마다 기대 주제(`expect`, 첫 번째가 1순위)·제외 주제(`not`)를 확인한다. 약칭·부칙은 `node tests/check-abbr-supp.js`로 확인한다(법제처를 부르지 않는다). 이름으로 찾은 법령의 결과 순서는 `node tests/check-order.js`(Playwright, 가짜 법제처 응답)로 확인한다. 새 표현을 보강하면 질문도 함께 더한다.
- **법제처 법령용어 사전**: 상황 사전으로 주제를 못 잡으면 질문의 낱말 2개까지 `lawService.do?target=dlytrmRlt`(일상용어-법령용어 연계, 법령정보지식베이스)로 법령용어를 받아 다시 맞춰 보고 검색어에 더한다. 4초 안에 답이 없거나 인증키에 이 서비스가 허용되지 않았으면 건너뛴다.
- **AI 질문용 글(프롬프트 복사형)**: 결과 아래 'AI 질문용 글 만들기'가 상위 법령(법령 3개 + 행정규칙 1개)에서 조문을 최대 10개 골라 질문·답변 규칙과 함께 묶는다. 페이지는 AI를 부르지 않으며, 방문자가 복사해 자기 AI에 붙여 넣는다. 면책·개인정보 경고 문구를 지우지 않는다.

참고용 도구이며 법률 자문이 아닙니다. 중요한 판단 전에는 국가법령정보센터 원문을 확인하세요.

## trade/ — Happy Oh 무역통계 길잡이
- `trade/index.html` : HS코드 찾기, 한국 수출 상대국 순위(관세청+UN Comtrade 비교), 세계 수입시장·한국 점유율, 연·월 추이. 주소: `/lawsearch/trade/`
- `trade/proxy.gs` : Google Apps Script 중계 서버(관세청 인증키 숨김·CORS 우회). 배포 방법은 파일 상단 주석 참고. 배포 후 `index.html`의 `DEFAULT_PROXY`에 웹 앱 URL을 넣는다.
- 한국무역협회(K-stat)는 공개 API가 없어 링크로만 연결한다.

## cert/ — 옛 해외인증 길잡이 주소(이동 안내)
2026-11-22 KOTRA API 검색형 '해외인증 길잡이'를 홈페이지(export3)의 정적 페이지 `cert-guide.html`(해외인증 조회 가이드)로 대체했다. `cert/index.html`은 새 주소로 바로 넘기는 안내 페이지(`noindex`, canonical = 새 주소)만 남는다. 무역통계 길잡이의 [해외인증] 버튼도 새 페이지로 연결한다. 중계 서버 `proxy.gs`의 `a=cert` 등 KOTRA 해외인증정보 API 연결 코드는 이동이 문제없으면 2026-12 하순에 지운다(작가님 결정).

## buyer/ — Happy Oh 바이어 검색 길잡이
한국무역보험공사 「바이어 검색」(공공데이터포털, `apis.data.go.kr/B552696/buyer/getBuyerList`)을 국가(필수)·업종(1~4단계)·품목명·바이어명으로 조회합니다. 국가·업종 코드는 `codes.json`(무보 코드집 xlsx에서 변환). `trade/proxy.gs`의 `buyer` 동작(`DATA_GO_KEY` 사용)을 거칩니다. 요청 변수: `ctryCd`, `industryCd`, `prodNm`, `buyerNm`, `pageNo`, `numOfRows`. 응답 필드 이름은 패턴으로 찾으며, 화면의 '응답 항목 전체 보기'로 원문을 확인할 수 있습니다.
